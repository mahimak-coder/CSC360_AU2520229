# Reflection on Today's Graphics Class.

During the graphics class today, I had to recognize that even a somewhat basic concept like a moving “s”quare can be a lot of thinking. I really enjoyed that when we got started, we didn't go straight to the coding but went back to the basics of it. I needed to consider things such as the position and size of the square, where the square should begin, where the coordinates will determine on the screen and so on before I came up with any ideas that I could use to draw the square. This helped me to be more familiar with graphics rather than being merely code.

As I'm working through line by line, I discovered every line of the program had a function. Gaining knowledge of **JFrame, packages, and Java program structure** allowed me to feel at ease with the graphics programming. Okay I'd just seen these things before as some weird line of code but now that I'm starting to understand why they're needed.

I also learnt about the structure of the project and Tools used to develop the project – also POM.xml, Target, Object and Static fields. It made me aware that programming isn't just writing the primary program; there's a whole environment behind it, which aids us to build and run the project.

What I've learnt today is nothing but to reflect on the logic first before coding. To apply motion to any shape, we must first find out what its position and coordinates are, and then based on that, determine how it will affect them to produce the motion. This approach will assist not only with graphics, but also with other types of programming problems. In general, today's class inspired me to be interested in making and controlling graphics with some simple shapes and I feel I have a much better understanding of the basics of graphics programming.
