## Digital Image

A digital image can be represented as a collection of values.

- A digital image can be represented using a matrix.
- Each cell of the matrix represents a value.
- The values represent information about the image.
- A photograph can contain RGB (Red, Green, Blue) values.

### Black and White Image

- A black-and-white image can be represented using a single value.
- The value represents the intensity of the pixel.

### Image Creation

An image can be created by assigning values to different positions (rows and columns) of the image matrix.

## Image as Information

An image is a way of storing and representing information.

A digital image can be represented as a **matrix of pixels**. Each pixel contains a value that represents some information about that particular position in the image.

## Raster Graphics

Raster graphics represent an image using **pixels**.

- A raster image is made up of a large number of pixels.
- The pixels are arranged in rows and columns, forming a matrix.
- Each pixel stores information such as colour or intensity.
- Higher resolution generally means that the image contains more pixels and therefore more image information.
- When a raster image is enlarged too much, individual pixels can become visible and the image may lose quality.

**Example:** Digital photographs are commonly represented as raster images.

## Vector Graphics

Vector graphics represent images using **geometric shapes and mathematical information** rather than individual pixels.

- Shapes such as lines, curves, circles, and polygons can be represented mathematically.
- The computer uses this information to draw the required shape.
- Vector graphics can be resized without the same pixelation problem seen in raster images.
- They are useful when the image consists mainly of clearly defined shapes.

**Example:** Logos, diagrams, and geometric drawings can be represented using vector graphics.

## Raster Graphics vs Vector Graphics

| Raster Graphics | Vector Graphics |
|---|---|
| Made up of pixels | Made up of geometric shapes |
| Represented using a pixel matrix | Represented using mathematical/geometric information |
| Enlargement can cause pixelation | Can be resized while maintaining shape quality |
| Suitable for photographs | Suitable for logos, diagrams, and shapes |

## Geometric Transformations

Geometric transformations are operations used to change the position,
size, or orientation of a graphical object.

The main transformations discussed are:

### 1. Translation

Translation means **moving an object** from one position to another.

For example, a shape can be moved from the left side of the screen
to the right side.

### 2. Scaling

Scaling means **changing the size of an object**.

- Scaling up → makes the object larger.
- Scaling down → makes the object smaller.

### 3. Rotation

Rotation means **turning an object around a fixed point** by a
specified angle.

These transformations are commonly used in computer graphics to
manipulate objects.
