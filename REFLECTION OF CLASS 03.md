# Reflection of the Class

Today’s class was mainly focused on setting up the basic structure for our Java graphics task. We started by understanding how we can create a shape on the screen and control its movement. The main task was to set up a square and make it move from one position to another on the screen. Also the part which was behind the setup was also difficult like setting up java and then then whole program linking with each other.

Initially, the setup took some time because we had to understand how the screen, coordinates, and shape positions work together. We learned that changing the x and y coordinates helps us move the shape horizontally and vertically. We also worked on the basic code required to display the square and set up its movement.

The class was mostly about getting the basic setup working rather than completing the entire project. We faced a few small issues while running the code, but solving them helped us understand the process better. Overall, today’s class gave me a better idea of how Java can be used for graphics and how simple movements can be controlled through coordinates and code.

I think this basic setup will make it easier to work on more advanced movements and shapes in the upcoming classes.
